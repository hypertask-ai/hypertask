## How to use a call

| Call | Do |
| --- | --- |
| delete | Read the named behaviour test. Removes the same guarantee? Remove the file and its allowlist entry in the same batch PR. Every file the assertions read is imported by some behaviour test, which is still not proof that the exact assertion is redundant. |
| rewrite | Remove the source-text assertions and keep the behaviour tests. Port an assertion into a behaviour test only when it guards something the file does not already check. |
| keep | Leave it. The evidence column names the guard, so a later pass can challenge one row at a time. |
