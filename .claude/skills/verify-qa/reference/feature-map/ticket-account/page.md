# Ticket account switch

With one signed-in account, `/detail/project-{id}/1` stays the open address. `POST /api/auth/ticket-account-switch` answers JSON containing `action` and no ticket title. With `htpr-9621-auto-switch-account` on, default mode OWNER_AND_QA, a ticket address the signed-in account cannot open asks the server which other account already signed in on this device can open it. One account becomes the active session and the browser returns to the same ticket. None leaves the unavailable page. Several return with a mark that opens the existing account switcher, and the pick stays on the ticket. The reply carries no title, email, account id, or session token. The flag off leaves today's page. Do not change the flag audience. Closest proof is `tests/htpr-9621-auto-switch-account.test.cjs`.
